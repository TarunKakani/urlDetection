# Phishing URL Detection: host-only character CNN

A lightweight phishing detector trained from scratch on hostnames from the
PhiUSIIL dataset. No pretrained models or transfer learning are used.

## Quick start

The trained models are included, so the detector runs straight after cloning:

```bash
pip install -r requirements.txt

python src/predict.py paypal-account-verify.top github.com   # command line
python src/predict.py --file urls.txt                         # one URL per line
python src/predict.py --json some-site.xyz                    # machine-readable

streamlit run src/app.py                                      # demo UI
```

## Repository layout

```
src/                 notebooks (one per phase), features.py, predict.py, app.py
models/              host_cnn.pt, host_bilstm.pt, thresholds.json
data/features/host/  vocab.json (character vocabulary used by the models)
data/zeroday/        zeroday_eval.csv (fresh phishing + legitimate hosts, Oct 2026)
results/             metric tables and plots from every phase
```

**Not in the repo** (see `.gitignore`): the raw dataset, the splits, the encoded
feature arrays, the classical baseline models and the raw probability arrays.
All of them are regenerated by running the notebooks in order.

## Data

* **Training data:** PhiUSIIL Phishing URL Dataset (UCI ML Repository, dataset 967,
  CC BY 4.0). Download it and save it as `data/raw/url_dataset.csv`.
* **Zero-day set:** phishing hosts from the OpenPhish free feed; legitimate hosts from
  the Tranco top-1M (ranks beyond 10,000) and, for platform-hosted sites, the Cisco
  Umbrella top-1M. Every host present in PhiUSIIL was excluded.

## Verdicts

| Verdict | Meaning |
|---|---|
| PHISHING | CNN score above the threshold that flags 1% of 2,000 long-tail legitimate domains (Tranco) |
| SUSPICIOUS | Above the PhiUSIIL-validation 1% FPR threshold, below the strict one |
| LIKELY LEGITIMATE | Below both thresholds |
| CAN'T JUDGE | Subdomain of a shared hosting platform (`vercel.app`, `github.io`, `pages.dev` ...) |

Both thresholds were fixed before the test and zero-day sets were scored.
The BiLSTM score is shown alongside, and disagreements between the two models are noted.

## Results

| | CNN | BiLSTM | TF-IDF baseline |
|---|---|---|---|
| PhiUSIIL test ROC-AUC | **0.920** | 0.910 | 0.915 |
| Test recall at 1% FPR (val threshold) | **69.6%** | 65.6% | 64.2% |
| Zero-day own-domain ROC-AUC | 0.898 | 0.903 | 0.882 |
| Zero-day recall at strict 1% FPR | 40.8% | **59.2%** | 15.3% |
| Legitimate platform-hosted sites flagged | 99.1% | 91.9% | 97.5% |

## Limitations

* **Hostname only.** Compromised legitimate sites and ordinary-looking domains are invisible.
* **Hosting platforms.** Anyone can create `x.vercel.app`, so the tool abstains there.
* **Brand on a foreign TLD** (`roblox.com.gr`) is usually missed.
* **Over-flagged:** non-Latin (IDN) domains, cheap TLDs such as `.top` and `.xyz`, and digit-heavy names.
